## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |
| **แก้อย่างไร** | เปลี่ยน**จากอะไร**เป็น**อะไร** | "เอาวงเล็บออก จาก `onClick={fn()}` เป็น `onClick={fn}`" |

> เคล็ด: เลขบรรทัดดูได้จากแถบซ้ายใน VS Code หรือจากข้อความ error ใน Console (เช่น `RequestList.jsx:9`)

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด | สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป | SummaryPanel.jsx : 13 | ไม่ได้ใส่ class name | ใส่หลังspan className="summary-card-label" |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง |DashboardPage.jsx : 51 | ไม่ได้เรียกใช้requestsเพื่อนโชวข้อมูลแบบตัวเลข | เติม requests ไห้เรียกใช้ของเดิมเป็นค่าว่างทำไห้ข้อมูลไม่ขึ้น |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) | DashboardPage.jsx : 50 55  | ไม่ได้เรียกใช้statusFilter มีชื่อstatus ซ่ำกันในบรรทัดที่ 50 | แก้ชื่อ satatus ไห้ไม่ซ่ำกัน แก้บรรทัดที่ 55 ไห้ใช้งาน statusFilter |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน | RequestDetailPage : 28 | ไม่ได้ใส่ requestId | ใส่ requestId เพื่อไห้ทำการโหลดข้อมูลใหม่ทุกครั้งที่กรอก id |
